## 🎯 О проекте

**CalculatorCpp** — учебный проект консольного калькулятора, демонстрирующий:
- Объектно-ориентированное программирование (классы, наследование)
- Работу с файлами (сохранение/загрузка)
- Обработку пользовательского ввода
- Статистику и историю операций

```
Автор: ArtickArts

Язык: C++ (C++11+)
Платформа: Windows (Linux/macOS — с доработками)
```

## ⚙️ Требования

| Компилятор | GCC, Clang или MSVC с поддержкой C++11 |

## 🚀 Сборка и запуск

### Windows (MinGW/GCC)
```bash
g++ -std=c++11 -o CalculatorCpp.exe main.cpp
CalculatorCpp.exe
```

### Windows (MSVC)
```cmd
cl /std:c++11 main.cpp
main.exe
```

### Linux/macOS ⚠️
Требуется заменить `_getch()` на кроссплатформенную реализацию (см. советы в коде).

## 🧮 Режимы калькулятора

Переключение: клавиши **`+`** / **`-`**

| Режим | Код | Описание |
|-------|-----|----------|
| 🔢 Арифметический | `0` | Сложение, вычитание, умножение, деление, степень, корень |
| 📐 Алгебраический | `1` | Решение квадратных уравнений, проценты |
| 📏 Геометрический | `2` | Теорема Пифагора |
| 📊 Тригонометрический | `3` | Вычисление синуса |
| 🐛 Debug Mode | `-10` | Отладка: просмотр массивов, статистики, истории |

---

## 🎮 Справочник команд

### Общие команды (работают во всех режимах)
| Команда | Описание |
|---------|----------|
| `0` или `e` | Выход из программы |
| `s` | Переключение режима ввода (стандартный ↔ быстрый) |
| `+` / `-` | Смена режима калькулятора |
| `d` | Вход в Debug Mode |

### Арифметический режим
| Команда | Действие |
|---------|----------|
| `1` | Сложение: `a + b` |
| `2` | Вычитание: `a - b` |
| `3` | Умножение: `a * b` |
| `4` | Деление: `a / b` |
| `5` | Степень: `a^b` |
| `6` | Квадратный корень: `√a` |

### Алгебраический режим
| Команда | Действие |
|---------|----------|
| `1` | Решение квадратного уравнения `ax² + bx + c = 0` |
| `2` | Проценты `b% от числа a` |
| `3` | Арифметическая прогрессия (найти n член и сумму n членов) |

### Геометрический режим
| Команда | Действие |
|---------|----------|
| `1` | Теорема Пифагора: выбор — найти катет (`1`) или гипотенузу (`2`) |

### Тригонометрический режим
| Команда | Действие |
|---------|----------|
| `1` | Вычисление синуса: `sin(a)` *(угол в радианах)* |

## 💾 Файлы данных

### `history.txt`
```
<количество_записей>
<операция 1>
<операция 2>
...
```
*Пример:*
```
3
2.00 + 3.00 = 5.00
4.00 * 5.00 = 20.00
√9.00 = 3.00
```

### `stats.txt`
```
<сложение>
<вычитание>
<умножение>
<деление>
<степень>
<корень>
<квадр_уравнения>
<проценты>
<пифагор>
<синус>
```

### `settings.txt`
```
<режим_ввода: 0=стандарт, 1=быстрый>
<текущий_калькулятор: 0-3>
<количество_ошибок>
```

> 📌 Файлы создаются автоматически при первом запуске.

## ⚙️ Настройки

| Индекс | Название | Значения | Описание |
|--------|----------|----------|----------|
| `ENT` (0) | Режим ввода | `0` — стандартный (Enter), `1` — быстрый (одна клавиша) | Способ подтверждения команд |
| `CALC` (1) | Текущий режим | `0`–`3` — калькуляторы, `-10` — Debug | Активный модуль программы |
| `ERR` (2) | Счётчик ошибок | `0` и более | Количество некорректных вводов |

## 🐛 Debug Mode

Вход: команда **`d`** в главном меню.

| Команда | Описание |
|---------|----------|
| `1` | Показать значения массива `mas[]` (скоро добавлю settings[]) |
| `2` | Статистика по типам операций |
| `3` | Общая статистика сессии |
| `4` | Просмотр истории операций |
| `5` | Очистить историю и статистику |
| `0` | Выйти из Debug Mode |

---

## ⚠️ Известные ограничения

| Ограничение | Рекомендация |
|-------------|--------------|
| `_getch()` работает только на Windows | Для кроссплатформенности реализовать альтернативу через `<termios.h>` |
| Углы в тригонометрии — в радианах | Добавить конвертацию градусов → радианы |
| Нет обработки переполнения `float` | Использовать `double` или проверку `isinf()`/`isnan()` |
| История хранит только 10 последних записей | Увеличить лимит или добавить настройку |
| Нет поддержки выражений типа `2+3*4` | Реализовать парсер выражений (опционально) |

## 🛠️ Частые вопросы

**❓ Почему не работает ввод на Linux?**  
→ Функция `_getch()` из `<conio.h>` доступна только в Windows. Нужно заменить на реализацию для Unix.

**❓ Где сохраняются данные?**  
→ В текущей папке запуска: `history.txt`, `stats.txt`, `settings.txt`.

**❓ Как сбросить настройки?**  
→ Удалите файлы `.txt` или используйте очистку в Debug Mode (`5`).

**❓ Почему синус выдаёт странный результат?**  
→ Функция `sin()` принимает угол в **радианах**. Скоро будет исправлено`.
